# CUDA p-norm 1..4 gate (2026-08-10)

## Matrix

- Device: NVIDIA GeForce RTX 5080, compute capability 12.0
- Build: Release, CUDA 13.3, production `cpp-generic` fatbin
- Fixture: `synthetic-trigonometric-v1`, 1920x1080 to 1280x720
- Search: 64 Lanczos3 candidates, both axes, concurrency 1
- Timing: 3 warmups and 5 measured waves; table values are medians
- Command: `getnative_cuda_throughput_benchmark --full --samples 5 --axes both --p-norm N`

CPU comparisons use `--compare-cpu`, which runs the same source, plans,
candidates, metric, warmups, and samples through the automatic CPU batch path.
The CPU phase is excluded from the isolated GPU regression samples.

All p2..p4 medians remain within 5% of the paired p1 run and exceed the 3x CPU
throughput requirement. Checksums were stable across all five samples for each
norm.

## Correctness and resources

`getnative_cuda_baseline_tests` covers p1..4 for horizontal, vertical, and both
axes; crop and nonzero threshold; exact strict-threshold equality; tail shapes;
single candidates; multi-tile p4; per-candidate CPU tolerance; minimum-step
stability; and the top-three local-valley set. Explicit p0, p5, and uint32-max
CUDA norms are rejected.

`getnative_cuda_artifact_inventory` passed for the complete native/PTX target
inventory. Every native kernel retained zero stack and zero local-memory use.
